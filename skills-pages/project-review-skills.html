project-review-skills

Bootstraps a full review framework inside a target repository and tailors checks to the detected language, framework, dependencies, and source layout.

Back to Home

What This Skill Generates

  • 2 agents: security reviewer and quality reviewer
  • 6 orchestrator skills for full, summary, and single-domain reviews
  • Project-specific checks driven by real source files and dependency versions

Command to Copy

npx skills add https://github.com/thinktalentservice-ai/project-review-skills --skill project-review-skills

How to Run

  1. Open your target repository.
  2. Install this skill with the npx command above.
  3. Start Claude Code and run /project-review-skills.
  4. Review and commit the generated .claude agents and skills files.

Supported Build Manifests

pom.xml, build.gradle, pyproject.toml, requirements.txt, package.json
